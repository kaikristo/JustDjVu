# Third-party components

## DjVuLibre 3.5.29

JustDjVu distributes the `ddjvu`, `djvused`, and `djvutxt` executables together
with the required dynamic libraries from the official DjVuLibre build for
Windows.

- Project: <https://djvu.sourceforge.net/>
- Source code: <https://github.com/DjVuLibre/DjVuLibre>
- License: GNU General Public License, version 2 or later
- License text: `JustDjvu/Tools/DjVuLibre/COPYING.txt`
- Source archive for the corresponding version:
  <https://sourceforge.net/projects/djvu/files/DjVuLibre/3.5.29/>

DjVuLibre is executed as a separate process. JustDjVu does not modify its
binaries.

## 7-Zip

7-Zip was used only while preparing the third-party files. It is not included
in the JustDjVu source code or distribution.
